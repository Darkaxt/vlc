# VLC player design assets

`mpv.ico` contains the original16/24/32/48/64/256px Windows icon payloads extracted
from the installed MPV202611051247 executable. The reconstructed group is byte
identical to upstream `etc/mpv-icon.ico` at3138fc8eea. [mpv-source.json](mpv-source.json)
records the PE, group, individual frames and upstream blob hashes, extraction
command and GPL-2.0-or-later provenance. The matching original PNG frames preserve
every decoded RGBA pixel because the pinned Qt build has no ICO decoder.

The user's optical-size correction uses `mpv-display-*.png` and
`mpv-display.ico`, generated by `tools/windows-player/generate-mpv-display-icons.py`.
Only fully transparent padding is cropped from the largest original256px frame;
display sizes are downsampled with premultiplied-alpha Lanczos. The exact recipe
and hashes are in [mpv-display-source.json](mpv-display-source.json). QML, QIcon
and the packaged Windows Shell icon use these same frames. Original extracted
resources remain intact. Native DPR comparison verifies the displayed circle.

VLC and MPV have independent saved accent palettes. Defaults are VLC orange
`#d37918` and visible MPV-logo purple `#9859ad`. Custom MPV icons preserve
neutral details, alpha and shading while recoloring chromatic regions; profile
cache version2 separates the optical-size frames from earlier generated icons.

These transparent SVG masks derive from Juxtopposed's **VLC Redesign**, licensed
under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribution and
editable reference links are in [the design resource index](../../../../../doc/redesign/resources/README.md).

The canonical archive is `doc/redesign/resources/vlc-redesign.fig`, SHA-256
`86637a31ad4ffbcaddc89244e0588df2c0cbe0954a6fe87c7bf5b6a65345e49e`.
[manifest.json](manifest.json) records each original component ID and output hash.
The source vectors have been converted to white masks for native light/dark
tinting; the Figma component canvas is omitted. Saved path geometry and nested
affine matrices are retained. Rectangle primitives use their current dimensions,
radius and stroke alignment, rather than potentially stale geometry caches.

M2 restores the default outlined sidebar component `69:814` and the original
two-tone main-menu and Playback-tab components recorded in the manifest. Their
neutral/orange paints are retained rather than flattened to a single mask.
Inside-aligned closed vector stroke outlines use their saved fill contours as
SVG masks, supported by Qt6.8. Open contours keep their saved centered outlines:
masking those would erase radio waves and the sidebar divider. Qt ignores
clipPath, so exports must not depend on it. Original commands and curves remain
unchanged. The retained Qt6.8.3 renderer verified the closed-frame bounds, complete
open radio waves and divider at24/30/36/48/384px. Full-player comparison with the
interactive reference remains required before release.

Reproduce with the locked design-source dependencies and
`node tools/design-source/player-assets.mjs <explicit-output-directory>`.
Temporary dependencies and exports must use the task's E: scratch root.
The extraction does not use Figma credentials or the screen renderer.

The cone volume control uses saved vectors `244:211` and `244:214` in
`volume-cone.svg` and `volume-level.svg`, including the inner inset, gradient,
dark overlay and clipping. It uses VLC's existing SVG plugin.
Native appearance comparison remains separate from binary/path verification.

S4 adds the archived Home (`70:828`) and Network (`70:833`) components and the
library search/view/navigation masks. The offline screen renderer reduced a
reflected matrix to a rotation, producing detached Home/Network fragments near
the left edge. These screen renderings are unsuitable as an icon oracle. The
production SVGs retain every signed affine matrix; the source/reflection
regression checks bind these component IDs. Final native pixels still require
visual verification against the design contract.
